# kod_asistanim
#proje Yazarı:BERAT CUMA KARADENİZ
#Projenin Adı:Kod-asistan v0.1
## Projenin Amacı: Kullanıcılara günlük işlerinde (hesaplama, selamlama vb.) yardımcı
olacak bir dijital asistan tasarlamak
## Projenin Hedefleri: Bu asistanın ilerliyen zamanlarda hangi özellikleri kazanacagı
*Selamlama v1.0
*Kolay veri girişli dört işlem yapan hesaplama uygulaması v1.1
*hesaplarının sonuçlarını ondaklı gösterebilme v2.0
*hatalı veri girişini engelleme v2.1
## Projenin kapsamı:
* girilen iki sayı toplama, çıkarma, çarpma ve bölme işlemi yapabilmek
    * Başla
    * "1.sayı:" gir,a
    * "2.sayı:" gir,b
    * toplam-a+b
    * fark-a-b
    * çarpim-a*b
    * bolum-a/b
    * Yaz "a+b-",toplam
    * Yaz "a-b",fark
    * Yaz "a*b",carpim
    * Yaz "a/b",bolum
    * BİTTİ
